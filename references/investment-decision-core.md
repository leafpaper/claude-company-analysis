# 投资决策内核框架（v7.0）— 五篇理念的统一操作手册

> **来源**：贝叶斯之美 / BayesCrest 五篇——《投资是泊松过程》《喊线时代》《当我们无路可走时·三大数学模型之美》《信仰投资最大陷阱》《十年十倍股复盘》。
> **用途**：§四 4.11 状态评估 / §五 估值赔率 / §六 6.4 左尾 / §七 投资决策内核 / §一 决策结论 的**权威定义来源**。每个机制都要求产出**具体可检验**的东西，不是哲学空话。

---

## 0. 总公式

> **投资价值 = 状态后验（贝叶斯）× 赔率（定价充分度）× 路径可承受性**　——乘法，任一为"差"即拉低整体。
> **长期结果 = 更新能力 × 等待能力 × 右尾捕捉 × 左尾毁灭风险。**

它把错问题"是不是好公司"，替换成三个分开的问题：
**① 是否正在变好（状态后验）→ ② 是否已被价格吸收（赔率）→ ③ 兑现前能否承受（路径）**，并据此分出 **好公司 ≠ 好下注 ≠ 好价格**。

## 1. 状态后验（"正在变好吗？被独立证据确认吗？"）— 落 §四 4.11，合成于 §七 7.1

### 1.1 λ（向上状态跳变强度）— 泊松
投资不是连续收益，是稀疏事件驱动的状态跳变。你买的是 **λ = 向上跳变的强度**。
- **按资产类型定义 λ 的载体**：财报型公司=连续超预期的财报；AI receiver=订单/客户验证；周期股=供需反转；软件股=净留存/渗透；事件驱动=并购/分拆/政策。
- **必须产出**：本标的的核心**状态跳变事件**是什么；λ↑ 的具体信号（订单/收入加速/客户验证/管理层底气/行业景气）；**★分部级 λ**——若高 λ 的只是一个小分部，要注明它是否被集团主体稀释。

### 1.2 证据网络临界密度 — 泊松
λ 上升不够，要多个**独立**信号互相印证达到临界密度。
- **独立证据 vs 同一叙事回声**：客户在买 / 收入加速 / 利润率没崩 / 订单增长 / 行业趋势配合 / 股价尚未完全反映——逐条标"独立✓ / 回声✗"。券商转述、口号、单条新闻＝回声。
- **必须产出**：信号清单逐条分类；是否达临界；**临界点 = 哪个未来事件**（如中报分部披露）。

### 1.3 贝叶斯三问 — 三大模型
对"公司正在迁移到更好状态"这个假设：
1. **后验真的提高了，还是只是注意力提高了？**
2. **新证据是独立证据，还是同一叙事的重复回声？**
3. **价格是否已充分甚至过度反映了这个后验？**
外加一句解放：**不要把先验当信仰**——先验（好公司）是好起点，但证据变了要愿意更新。

### 1.4 无记忆性 — 泊松
"跌久了该涨 / 沉寂久了该轮到 / 讲多年 AI 该兑现 / 估值压久了该修复"都是**等待时间幻觉**。买入理由必须是 **λ↑ 或证据斜率变正**，不是"已经等了很久"。（anti_lazy_lint Rule 7 机械拦截。）

### 1.5 身份切换 P1→P4（生产函数位置）— 喊线
市场最爱"重新命名"。一旦旧身份→新身份，估值表从 PE 看 → 用远期期权看。
- **P1**=普通参与者；**P2**=细分优势；**P3**=赛道龙头；**P4**=新生产函数瓶颈节点候选（被市场整体重命名，如 MRVL connectivity→AI 基建瓶颈；ARM=P4 但价格高度提前）。
- **必须产出**：旧身份→新身份候选；当前 P 几；**是否真正完成重命名**（主体是否仍是旧身份）。

### 1.6 升级基本面定义 5 元组 — 喊线
近端 EPS 不够，用 5 元组替代："生产函数位置 / 约束释放能力 / 权威认证 / 证据再验证节奏 / 定价充分度"——逐项判。

### 1.7 四层验证 + 权威认证 — 喊线
1. **能一句话传播？**（讲不清→难成大规模资金共识）
2. **有真实产业约束接棒？**（订单/收入/客户/毛利/FCF，不是纯喊话）
3. **有权威节点认证？**（黄仁勋式权威分发 vs 券商转述回声——**Authority Certification Event 改变叙事/注意力/定价，但不证明 Business Truth**）
4. **价格是否已买完完美未来？**（详见 §五，喂赔率）
逐层 ✓/✗ + 依据。

## 2. 赔率 / 定价充分度（"已被价格吸收了吗？"）— 落 §五，合成于 §七 7.2

### 2.1 价格分解 P = 基本面F + 叙事溢价N — 信仰陷阱
- **F** = 近端可见业务的保守估值（主业行业倍数 + 已兑现分部）。**N = 现价市值 − F**。
- **R = F/(F+N) − 1**：N 越大、回报越低。
- **N'/N vs F'/F**：当驱动股价的叙事增速 > 基本面增速（N'/N > F'/F）→ **信念越强、股票越贵、回报越差**（数学死穴：信仰者却 Belief↑⇒仓位↑）。
- **free option vs embedded obligation**：高估值下，远期可选项**不是免费看涨期权，是市场要求必须交付的义务**，否则估值回吐。
- **必须产出**：F 与 N 的**金额**；N 在为什么定价；option/obligation 判定；N'/N vs F'/F 方向。

### 2.2 反向 DCF：市场隐含预期 — 喊线④ + 信仰陷阱
从现价**倒推**市场隐含的增长 / 终端利润率 / 退出倍数，逐条判可信 + 给证伪条件。把"极致 price-in"从机械回避变成可检验问题。
- **必须产出**：隐含假设表（隐含值 + 历史/同业参照 + 可信? + 证伪条件）+ 结论（可信 / 过度乐观 / 买完完美未来）。

### 2.3 ΔP 传播因子分解 — 喊线
本轮上涨 ≈ Authority × Narrative Compression × Attention Velocity × Marginal Buyer Urgency × Peer Resonance × Gamma·Flow × Right-tail Optionality − (PFPC / Crowding / Valuation Exhaustion)。逐因子判强弱 → **是"权威认证驱动"还是"散户拥挤 + 估值耗尽驱动"**。

### 2.4 叙事分部 SOTP：拆分不混账 — 信仰陷阱解药①
多曲线公司各分部**各自合适倍数 + 各自证伪指标**，禁止单一笼统倍数盖全公司（PCB 按硬件倍数 / 光模块按 AI 同业倍数）。

### 2.5 十倍股估值视角 — 十年十倍股
Price = EPS × PE；十倍 = 盈利增长 × 估值扩张。**估值起点偏低**是十倍前提；PE 已在 100% 分位 → 扩张空间向下，只剩 EPS 单轮。又好又便宜罕见，常在极度悲观/错杀时。

## 3. 路径可承受性（"兑现前能扛吗？"）— 落 §六 6.4 + §五 5.6，合成于 §七 7.3

- **回撤 / 时间成本 / 机会成本**（信仰陷阱：特斯拉式"路径风险大、终点收益低"；时间不是免费的）。
- **假阳性成本**（泊松 EV 项：把回声当证据的代价）。
- **左尾毁灭**（幂律：减值 / 退市 / key-person / 踩踏 / 控制权丧失）。
- **高信仰股特征**（信仰陷阱）：高估值 / 高波动 / 高叙事弹性 / 高散户 / 高媒体 / 高期权活跃 / key-person → 上涨"信仰复利机器"，下跌"组合波动放大器"。
- **必须产出**：最大回撤情景 + 时间/机会成本 + 左尾清单 + 高信仰特征体检 → 路径判定（可承受 / 高尾险）。

---

## 4. 右尾 vs 左尾（幂律 + 十倍股）— 落 §四 4.11，纪律落 §七 7.4

- **右尾识别清单**（十倍股）：需求真实可延展 / 难替代提价权（征税权）/ FCF 自我造血 / 利润率持续提升 / 估值起点偏低——逐件 ✓/✗。
- **幂律来源**：需求函数巨变 / 供给短期刚性 / 瓶颈节点 / 规模越大越强 / 客户验证正反馈 / 资本市场提高终局后验 / 自强化循环——判**是不是"幂律生成器节点"**。
- **幂律陷阱**：涨多 ≠ 继续涨；热 ≠ 每个都是右尾；用平均估值看幂律赢家会觉得"永远贵"。
- **心法**：不在左尾毁灭 + 能识别右尾 + **右尾被证据确认时才敢给足合法仓** + 右尾衰减时贝叶斯更新 + 不把曾经的右尾当永恒资产（爱机制不爱标签，爱状态不爱过去的自己）。

## 5. 决策合成（§七 7.4）

### 5.1 决策三元组
`[状态后验 | 赔率 | 路径可承受性]`，各取值：
- **状态后验** ∈ {↑变好+证据确认, ↑变好但仅注意力·未确认, 横盘, ↓变差}
- **赔率** ∈ {便宜(有 slack), 合理, 已 price-in, 买完完美未来(无 slack)}
- **路径** ∈ {可承受, 高尾险·不可承受}

### 5.2 三分结论
**好公司?**（资产质量/护城河/赛道）· **好下注(现价)?**（状态×赔率×路径乘积）· **好价格?**（有无 pricing slack）——三个分开判，各带一句依据。好公司 ≠ 好下注 ≠ 好价格。

### 5.3 行动档位（六档）+ 映射
结合 **λ×payoff 四象限** + **高质量等待 vs 资本钝化** + **仓位纪律（叙事越远仓位越小，证据越近仓位越大）** + **现金=等待选择权**。

| 状态后验 | 赔率 | 路径 | → 行动档位 |
|---|---|---|---|
| ↑确认 | 便宜 / 合理 | 可承受 | **核心仓**（高 λ 高 payoff） |
| ↑未确认 | price-in / 买完未来 | 高尾险 | **等证据临界（观察）** 或 **期权仓（小）**（看右尾大小） |
| ↑ | 买完未来 | 可承受 | **不追高（贵但优质）/ 减仓** |
| ↓ 或（买完未来 且 高尾险） | — | — | **回避** |

- **核心仓**：高确信、有 slack、路径可扛 → 给足合法仓位。
- **期权仓（小）**：右尾大但未确认 → 小仓博右尾，叙事越远仓位越小。
- **等证据临界（观察）**：λ↑ 但证据未达临界 / 价格无 slack → 高质量等待（须有明确等待事件 + 退出条件；否则是"资本钝化/套牢自我安慰"）。
- **不追高（贵但优质）**：好公司但已 price-in → 不回避标的本身，只是现价不入场。
- **减仓 / 回避**：路径不可承受 / 买完完美未来无 slack / 状态向下。

### 5.4 信仰陷阱五弊端自检（§七 7.4 收尾逐条 ✓）
①好公司=好股票？②远期可选项当当期现金流？③坏消息当短期噪音、失去证伪？④时间当免费、忽略机会成本？⑤仓位由信念强度而非赔率证据决定？

## 6. 证伪 / 退出 + λ 监控（接 Phase 7）

- **每条核心叙事 1 个可证伪指标**（如"中报光模块分部营收/毛利不及预期 → 叙事崩"）。
- **退出触发**：λ 下降 / 证据斜率转负 / 关键证伪指标命中 / 左尾事件发生。
- **方法后验更新闭环**（三大模型）：证据 → 概率 → 赔率 → 仓位 → 复盘 → 方法后验更新。接 Phase 7 舆情/事件监控。
