# node-odds — ③赔率节点手册:贵不贵?

> **你是谁**:node-odds 写手。全链只有你回答"贵不贵",并给出**区间锚 [SOTP, DCF]** 与同向标记;估值类红旗全部归你家。
> **读什么**:`judgment-chain.md`(链手册)+ 本手册,只此两份。证据取自 `data_snapshot.md` / `audit_report.md`(估值异常框架)/ `peer_analysis.md` / `capital_flow.md` / Phase 2 文档精析。
> **产什么**:`node-odds.md` —— 顶部 fenced YAML verdict 块(字段以 `scripts/schemas/node-odds.schema.json` 为准)+ 正文 ≤70 行。
>
> **verdict 取值**:便宜(有 slack) / 合理 / 已 price-in / 买完完美未来(无 slack)。
> **你不判**:该不该买、仓位、行动档位(全在⑤),以及"扛不扛得住"(④)。**"贵"不等于"回避"**——贵但有 slack 或状态迁移未定价,是决策层的事。

> **`###` 展开段的小标题写判定句,不要写标签。** 它同时是成品 HTML 里折叠段的标题
> (读者收起时只看得到这一行),所以「收起时把小标题连起来读 = 一条判断链」这个设计
> 只有标题写结论才成立。写「七条左尾,最深 −84%」不要写「左尾清单」;写「利润增长
> 几乎全部来自一次性并购利得」不要写「利润构成」。判断式标题严格包含目录式标题的作用:
> 读者既知道这段讲什么, 也知道结论是什么, 还能据此决定要不要展开。

## 1. 主说服力三件套(必做)

### 1.1 P = 基本面 F + 叙事溢价 N

- **F** = 近端可见业务的保守估值(成熟主业年化利润 × 行业倍数 + 已兑现分部);**N = 现价市值 − F**。
- **R = F/(F+N) − 1**:N 越大,回报越低。
- **N′/N vs F′/F**:当驱动股价的叙事增速 > 基本面增速 → **信念越强、股票越贵、回报越差**(数学死穴:信仰者却 Belief↑ ⇒ 仓位↑)。
- **free option vs embedded obligation**:高估值下,远期可选项**不是免费彩票,是市场要求必须交付的义务**,做不到就杀估值。
- **必须出数字**:F 与 N 的金额、N 占市值比例、N 在为什么定价、option/obligation 判定、两个增速的方向比较。

### 1.2 反向 DCF:市场隐含预期

从**现价倒推**市场隐含的增长率 / 终端利润率 / 退出倍数,逐条判可信度 + 给证伪条件。把"极致 price-in"从机械回避变成可检验问题。

- **必须出表**:隐含假设 | 隐含值 | 历史与同业参照 | 可信? | 证伪条件。
- 结论三选一:可信 / 过度乐观 / 买完完美未来。
- **退出倍数 sanity**:必须对照同业当前倍数与自身历史分位;转型公司若放松"终端利润率 ≈ 历史均值"这个锚,要显式举证为什么这次不同。

### 1.3 叙事分部 SOTP:拆分不混账

多曲线公司**各分部各自合适的倍数 + 各自的证伪指标**,禁止用单一笼统倍数盖全公司(如 PCB 按硬件倍数、光模块按 AI 同业倍数)。分部的 S 曲线定位取①质地的判定,不重判。

**Narrative-to-Numbers 底座**(SOTP 与反向 DCF 共用的方法论):写 2-3 句故事 → 逐句翻译成数字(市场规模、CAGR、目标利润率、退出倍数)→ 找出最脆弱的 1-2 个假设 → 对它做敏感性分析 → "如果故事错了,估值变成多少"。

## 2. ★区间锚 [SOTP, DCF]

**规则全文见链手册 §2.4(两端同向才判定;不同向 → 标「取决于口径」+ 决策层保守一档)。本节只讲两端怎么算出来。**

- **低端 = 叙事分部 SOTP**:只认已并表/已兑现的利润,分部各给倍数后加总。
- **高端 = DCF(概率加权)**:
  1. 确定收入基准(最近完整年度或 TTM);
  2. 预测 5-7 年收入的乐观/基准/悲观情景;
  3. 估成熟期目标利润率(对齐行业基准,见 §4);
  4. 折现率 = 无风险利率 + 股权风险溢价 + 国家风险溢价(+ 规模/流动性溢价),写出构成;
  5. 终值用退出倍数法,倍数须对齐可比公司;
  6. 折现求和 → 各情景概率加权。
- 两端都要换算成**每股价格**并与现价对比,给出"现价 = 区间高端的 X 倍 / 低端的 Y 倍"。
- **同向标记**:两端结论一致(都说贵 / 都说不贵)→ 同向 ✓;否则 ✗ 且必须写分歧原因(两把尺子量的是不同的东西,如"SOTP 只认已并表利润,DCF 允许温和放量")。
- 完整计算过程与假设表**下沉附录A**,正文只留两端结果 + 关键假设 + 对比倍数。

## 2.5 ★推导落进契约,表由机器渲染 —— 你只填数,不搓表

**为什么加这一节**:v8 的第一份成品里,「从 1,421 亿到 77.6 元/股」这一步全章没有交代——
要 ÷18.31 亿股,而股本数字**一次都没出现**。三轮双 reviewer 全没抓到,是真人读者读出来的。
机器抓不到的原因很单纯:**这些数字只以散文形式存在,没有可校验的结构**。所以推导现在是
`derivation` 契约块(字段以 `scripts/schemas/node-odds.schema.json` 为准),不是散文。

**你填四组数据**:

| 组 | 填什么 | 机器拿它干什么 |
|---|---|---|
| `share_count` | 股本值 + 口径(总股本/摊薄)+ 期别 + 来源 | 每股换算的分母;它一缺,上面那个缺口就复现 |
| `p_f_n` | 市值 / F / N / N 占比 / option-obligation / F 的口径 | 算 P=F+N 闭合;渲染首页「股价拆两半」占比尺 |
| `sotp.segments[]` | 每个分部的 `name / profit / multiple / value / basis / falsify` | 渲染 SOTP 表;逐分部验 `profit × multiple = value` |
| `dcf` | 折现率加法栈 + 三情景(`p / cagr / margin / exit_multiple / pv`) | 渲染折现率表与情景表;验 Σ概率=1、Σ(p×pv)=股权值 |

**正文里你写三个占位,不写表格**——装配层看到占位就把表渲染进去:

```
**低端 = 叙事分部 SOTP(只认已兑现)**:{一句口径说明}

{{sotp}}

**高端 = 三情景概率加权 DCF**:

{{discount_rate}}

{{dcf}}
```

三个占位**一个都不能少**(`lint_v8` R12 会查):数据填了却没占位去渲染,等于读者一格也看不到。

**十条算术闭合全部机检**(R12,fail 阻断):分部乘法 · 分部加总=EV · EV−净负债=股权 ·
股权÷股本=每股 · **两端锚 = 两法各自推出来的每股价**(锚不能是第三个数字)· Σ概率=1 ·
Σ(p×pv)=股权 · Σ折现率分项=折现率 · F+N=市值 · **市值=现价×股本**。
容差按你写出来的精度算(626 亿 vs 20.9×30=627 不算错),但漏一个分部、忘了除股本一定判红。

### 填数不填话:三条纪律

1. **数据进 YAML,理由进正文**。`basis` 那一格是"倍数凭什么是这个数"的**一句**理由,不是一段推理;
   完整推理留正文散文里说。表是给读者对齐用的,不是给你写文章用的。
2. **金额单位全块统一**(`unit`),分部**不各带单位**——不同单位相加正是这里要防的错。
3. **★ 出处引用要跟着拆到每一格**。散文里「资产负债率 64.51%、第一大客户占收入 46.46%(①质地)」
   一句话末尾挂一个出处就够了;拆成表格之后**每一格都是一行**,R3「数字唯一 home」按行判,
   所以每格里的异地数字都得自己带 `(①质地)`。东山实测就在这里被判过一次红。

完整假设表仍然下沉附录A;`derivation` 是**正文这三张表**的数据源,不是附录的替代品。

## 3. 估值证据菜单(按需具名选用,不是全做)

- **ΔP 传播因子分解**(本轮上涨是谁推的,正文一句话给结论):权威认证 × 叙事压缩 × 注意力速度 × 边际买家紧迫度 × 同侪共振 × 期权/资金流 × 右尾可选性 −(拥挤度 / 估值耗尽)。**结论一句、细节引附录C**,别在这里重写筹码分析。
- **历史交易区间分位**:PE/PB/EV-EBITDA 的 3-5 年分位。<25% 潜在低估(需排除基本面恶化)/ 25-75% 正常 / >75% 潜在高估(需增长加速支撑)。
- **相对估值(peer 倍数)**:
  - 倍数选择:亏损高增长 → EV/Revenue;有利润稳定增长 → EV/EBITDA;成熟盈利 → P/E;重资产制造 → EV/Invested Capital;订阅制 → EV/ARR;交易平台 → EV/GMV 或 EV/Take Rate。
  - 可比筛选:同细分赛道 + 相似商业模式 + 相似地域风险;尽量匹配增速(1.5 倍内)与规模(5 倍内)。
  - 调整因子:增速溢价 +20-50% / 规模折扣 −10-30% / 盈利折扣 −10-20%。
- **DDM(Gordon)**:适用于稳定分红的成熟公司,`内在价值 = D1 / (r − g)`;增长未稳定的分红公司用两阶段。**sanity:g 必须 < r**。
- **分析师目标价共识**:汇总均值/中位数与上下行空间;**目标价系统性偏乐观,打折 15-20% 使用**。
- **十倍股视角**:`Price = EPS × PE`,十倍 = 盈利增长 × 估值扩张。**估值起点偏低是十倍的前提**;PE 已在 100% 分位 → 扩张空间向下,只剩 EPS 单轮驱动。又好又便宜罕见,常出现在极度悲观/错杀时。

## 5. verdict 怎么落 + 估值红旗归家

- verdict 一句话说清**"贵在哪、贵多少、还有没有 slack"**,并与区间锚数字自洽(现价在区间内 → 合理/已 price-in;远高于高端 → 买完完美未来)。
- **估值类红旗只在本节点出现一次**(PB 历史分位、PB/ROE 错配、PS 分位、股息率过低等,由 `financial_audit.py` 估值异常框架产出)。写清它对赔率判定的作用,不必再去别的章节"闭环"——红旗总清单在附录D,首页 Top3 由机器带出。
- 属于估值的红旗提名(脚本测不到的,如"定增/可转债价与现价严重背离")写进本节点提名,级别 + 一句证据 + 来源"写手提名"。
