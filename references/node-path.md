# node-path — ④路径节点手册:扛得住吗?

> **你是谁**:node-path 写手。全链只有你回答"兑现前扛不扛得住",并产出**左尾清单**与**证伪/退出清单**。
> **读什么**:`judgment-chain.md`(链手册)+ 本手册,只此两份。证据取自 `data_snapshot.md` / `audit_report.md` / `capital_flow.md` / `technical_analysis.md` / Phase 2 文档精析。
> **产什么**:`node-path.md` —— 顶部 fenced YAML verdict 块(字段以 `scripts/schemas/node-path.schema.json` 为准)+ 正文 ≤60 行。
>
> **verdict 取值**:可承受 / 高尾险·不可承受。
> **你不给仓位**:回报测算只产**证据**(期望收益/回撤/时间成本),仓位与行动档位唯一出处是⑤决策层。

---

## 1. 左尾清单(本节点的核心产物)

把"最坏会怎样"逐条摊开,每条给:**触发条件 + 传导路径 + 对股价的量级影响**。常见来源:

- **减值**:商誉/存货/应收/在建工程;并购形成的商誉要写明形成时点、占净资产比例、对赌条款是否披露。
- **偿债与资金链**:有息负债到期结构、货币资金覆盖、财务费用飙升、再融资依赖(接①质地"财务底子"的判定,后果在这里推)。
- **关键人物 / 控制权**:实控人质押比例与平仓线、核心技术团队绑定与流失、股权纠纷。
- **叙事证伪**:如果故事被推翻,想象溢价(③赔率的 N)回吐多少 —— 引用③的 N 金额,不重算。
- **踩踏与拥挤**:散户户数骤增、两融余额相对历史中位数的偏离、大宗折价、限售解禁;拥挤结构明细见附录C。
- **退市 / 监管 / 法律**:非标审计意见、立案调查、行业禁令。

**★若核心资产可能被剥离,必须做剩余资产清单**(触发条件满足任一即做):

1. 核心子公司占合并净利 >30% **且** 存在被监管强制剥离 / 控制权丧失 / 被没收的可能;
2. 最新业绩预告"首亏/续亏"且预亏金额 >50% 净资产;
3. 公司在 PDF 原文自述"若某事件发生,可能面临……";
4. `audit_report.md` 有 🔴 红旗涉及核心资产减值。

清单形态(完整表下沉附录A,正文只留净值与对应股价):

| 项目 | 金额 | 来源 |
|---|---|---|
| 货币资金 / 交易性金融资产 | … | 资产负债表 |
| 非核心子公司净资产 | … | 年报子公司表 |
| 已剥离业务尾款、非核心固定资产/无形/IP | … | … |
| 上市公司壳价值 | 5-10 亿(A 股主板) | 经验值 |
| 减:有息负债(转债+借款) | −… | … |
| 减:清算/法律/裁员成本 | −… | … |
| **"纯壳+现金"净价值** | **…** | 对应股价 X 元(−N%) |

**禁止的写法**:悲观情景只写"按 1x PB 出售核心资产"而不加回非核心资产与现金、不扣负债;让"壳价值"和"现金"在悲观情景里静默消失;左尾情景与③赔率用不同口径的同一份资产。

## 2. 高信仰股体检(逐项 ✓/✗,给"下跌时会不会被放大")

高估值 / 高波动 / 高叙事弹性 / 高散户占比 / 高媒体热度 / 期权与杠杆活跃 / 关键人物依赖。

命中越多,上涨时是"信仰复利机器",下跌时是"组合波动放大器"。正文用一张 5-7 行小表给出命中数(如 5/5),并写一句这意味着什么。

## 3. 回报路径证据(只产证据,不产仓位)

用**三情景目标价模型**测算,然后把"路上要吃多少苦"写清楚:

| 情景 | 假设 | 时间框架 |
|---|---|---|
| 🟢 乐观 | 业绩超预期 + 估值扩张 + 催化剂兑现 | 12-24 个月 |
| 🟡 基准 | 按共识增长 + 估值维持 | 12-18 个月 |
| 🔴 悲观 | 业绩不及预期 + 估值收缩 + 风险事件 | 12 个月 |

每个情景:目标价 → 预期收益率 → 年化 → 概率加权期望收益。目标价所用的估值口径**必须与③赔率的区间锚同源**(引用,不另起一套)。

再补三项成本:

- **中途最大回撤**:即便终点是对的,路上可能 −50%,你扛不扛得住;
- **时间 / 机会成本**:时间不是免费的,"路径风险大、终点收益低"的标的要点破;
- **假阳性成本**:把回声当实锤追进去,遇到"业绩+估值+情绪"三重杀的代价。

## 4. 证伪与退出清单(全链权威)

- **每条核心叙事至少 1 个可证伪指标**,写成可核销的形式:指标 + 阈值 + 时间窗(如"H1 光模块营收 <40 亿或毛利率 <30%")。
- **退出触发**:λ 下降 / 证据斜率转负 / 关键证伪指标命中 / 左尾事件发生。
- 每条给 `triggered` 状态(命中 / 未命中 / 尚不可判)。**增量复查(`--review`)每次都会让你逐条核销这张单子**——旧的守护进程式 λ 监控已退役,监控职责由复查分诊接管。
- 决策层的"证伪/退出"直接引用本清单,不新编条目。

## 5. 风险证据标尺(判"扛得住吗"时对齐)

| 风险维度 | 低 | 中 | 高 |
|---|---|---|---|
| 客户集中度 | 前 5 大 <20% 收入 | 20-50% | >50%,或单一客户 >30% |
| 关键人物 | 无依赖 / 有继任计划 | 存在依赖 | 严重依赖且无继任 |
| 监管 | 环境稳定、合规到位 | 有不确定性但不致命 | 可能直接摧毁商业模式 |
| 法律 | 无已知纠纷 | 潜在诉讼可管理 | 正在进行的重大诉讼/立案 |
| 市场信号 | — | 分析师降级、盈利 miss ≥2 次/4 季 | 做空比率 >15%、非标审计意见 |

**空头逻辑链**:把最强的看空论证完整写成一条链(前提 → 传导 → 后果),再给它自己的证伪条件。这是路径判定的展开段,不是新结论。

**旧的"六项快筛"不再单独成章**:阈值已并入 `financial_audit.py` 静默机算,触发即产 🔴,并在决策层触发档位封顶(链手册 §2.3)。报告零篇幅,也不写"快筛全 PASS ≠ 安全"这类免责段。
