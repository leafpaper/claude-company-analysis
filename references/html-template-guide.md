# HTML 交付设计哲学 (v8)

> ⚠️ **本文件不含可执行 CSS / HTML**。真相源是三个模板文件:
> - `assets/html/report-v8.html` — 单报告骨架(顶栏锚点 + hero + 首页 + 五章 + 附录 + 主题切换脚本)
> - `assets/html/report-v8.css` — 全部样式(明暗双主题 token + 组件 + 三张图 + 响应式 + 打印)
> - `assets/html/compare-v8.html` — 产业链对比页骨架(复用上面那份 CSS,只加对比页专属块)
>
> `base.html` / `styles.css` / `components.html` 是 **v7 兼容通道**,只服务历史报告,新报告不走。
>
> **禁止凭记忆重写 CSS 或自创 class 名。** 出片由 `scripts/build_html.py` 完成,
> 它读上面的模板、填占位、跑成品自检 —— 没有"手写 HTML"这条路径。
> 本文件只解释**为什么这么设计**,供改模板的人与 reviewer-delivery 理解意图。

## 一、输出哲学

- **自包含**:CSS 全部内联,零外部 JS/CSS/CDN/网络字体 → 断网能打开、当附件能发走、十年后还能看
- **单文件**:一份 HTML 就是一份完整报告,不切片、不依赖同目录资源
- **成品可自检**:`build_html` 出片后逐项核对(决断卡五行 / Top3 / 面板指标 / 五章 / 附录),
  缺一项就退出码 2 —— **版式再好看,内容掉了就是废品**

## 二、双主题不是配色偏好,是契约

三态,缺一不可:

| 状态 | 怎么触发 | 谁定义 |
|---|---|---|
| 明 | 默认 | `:root` 上的整套 token |
| 暗(跟随系统) | 用户没手动切过 | `@media (prefers-color-scheme: dark)` 下的 `:root:not([data-theme="light"])` |
| 暗(手动选定) | 点顶栏 🌓 | `:root[data-theme="dark"]` |

**任何颜色都不许只在其中一处定义**。两套 token 内容必须同步改 —— 只改一处的后果是:
某个主题下文字和底色撞成一团,而你在自己的主题里永远看不见。

存储键 `ca-theme`,**与对比页、与 Inves-Report 站点共享** —— 读者在首页选了暗色,
点进报告不该被闪一下白。

## 三、红标三通道

红旗在正文里的标记,必须**同时**具备三条通道,任一单独可读:

1. **emoji**(🔴🟠🟡)—— 扫读时的锚点
2. **文字**(致命红旗 / 高级红旗 / 中级红旗)—— 色盲、灰度打印、屏幕阅读器唯一能拿到的
3. **底纹**(`--wash-r` / `--wash-y`)—— 余光可见的区域感

**不许裸靠颜色。** 三通道之外还有第四层:标记本身是链接,点击直达附录D 的对应条目
(悬停浮层 `.fw-pop` 在触屏与窄屏直接 `display:none`,避免撑出横向滚动)。

`🟢` 与 `ℹ️` **不标色** —— 它们是绿灯与信息更新,借红旗的视觉名头会稀释真红旗。

## 四、组件与它们的意图

### 首页(全部机器装配,人工只写导读)

| 组件 | class | 意图 |
|---|---|---|
| 事实条 | `.facts` / `.fact` | 第一屏答完「该不该买、什么价」——行动档位 / 质地 / 现价 / 锚区间 |
| 决断卡 | `.cards5` / `.dc` | 五问五瓦片,每张链到自己那章;左封条颜色 = 该节点的红旗载荷 |
| 赚钱面板 | `.tiles` / `.st` | stat tiles + 红标角标 + sparkline;**整列为空就不出这一列** |
| Top3 风险 | `.risks` / `.rk` | 机器从附录D 带出,不是人挑的 |
| 导读 | `.intro` | 全首页**唯一的人工位**,3-5 句 |
| 较上版变化 | `.change` | 仅增量复查;首句机器答「阿尔法变了没」 |

### 正文与附录

| 组件 | class | 意图 |
|---|---|---|
| 章节块 | `.chB` | 一章一块,`.pill` 判定语在章头 |
| 折叠段 | `details.drill` / `.foldbar` | 渐进披露。**summary 必须是结论句**——收起后连读应当是一条完整判断链 |
| 表格容器 | `.tblwrap` | 所有表格强制横滚容器,**页面本体永不横向滚动** |
| 附录导航 | `.appxnav` / `.ap` | 五格入口,附录本体 `.appx` |

### 三张契约图(数据来自 YAML,零写手工作)

| 图 | class | 画什么 |
|---|---|---|
| 估值尺 | `.meter` | 锚区间两端 vs 现价的位置关系 |
| 占比尺 | `.pfn` | P = F + N 的两段部分-整体 |
| 左尾阶梯 | `.ladder` | 由浅到深排台阶,**满格 = 本图最深那级**(不是 −100%,否则台阶会被压平) |
| 面板走势 | `.spark` | 指标序列;跨零时补零基线 |

> **图上文字的纪律**(票 10 交付评审连开两轮换来的):
> - **图例只放身份 + 数值**,算式与理由回正文的注 —— 否则每次拆完墙又在图里重建一堵
> - **图脚只说「还有几条、去哪看」**,明细在正文清单里(而且要确认那个"清单"在成品里
>   真是一张读者认得出的表,不是一段散文)
> - **截断交给 CSS**,Python 不加省略号;但要保证标签不停在半截数字或未闭合的括注里
> - 这些字段现在归 **lint R11** 机检(扫 YAML 源字段,不扫成品——lint 跑在出片之前)

## 五、响应式:改结构,不缩字号

**媒体查询里不得出现任何 `font-size`。** 手机上字变小不叫适配,叫惩罚。
窄屏要做的是**重排**:多列变单列、绝对定位变静态、sparkline 落到数值下一行。

断点与各自的职责:

| 断点 | 做什么 |
|---|---|
| `max-width: 980px` | 网格开始收窄 |
| `max-width: 720px` | 顶栏不再吸顶;红标浮层关掉 |
| `max-width: 620px` | 决断卡/面板/风险卡全部单列;角标由绝对定位改静态 |
| `(hover: none)` | 触屏:浮层关掉,改为点击直达附录D |
| `prefers-reduced-motion` | 关动效 |
| `print` | 去阴影、加边框、`break-inside: avoid`、折叠段全展开 |

> ⚠️ **`display:flex` 的容器在窄屏必须显式 `flex-wrap:wrap`**。
> 内容变短不等于版式变安全 —— 缺 `flex-wrap` 的缺陷只在内容长度跨过阈值时才显形,
> 实测出过「4,352.0 / 亿 · 43.4%」被挤成两条窄列(票 10 交付评审)。

## 六、质量门控

出片这一步有三道关,**都不是"看一眼觉得好看"**:

1. **`lint_v8`**(出片前,`build_html` 内置调用)—— fail 项不过就不出片
2. **`build_html` 成品自检** —— 决断卡五行 / Top3 / 面板指标 / 五章 / 附录逐项核对,缺一退出码 2
3. **`reviewer-delivery` 的 390px 走查清单** —— 在**成品 HTML** 上执行,不是看 md 猜:
   - 决断卡窄屏单列不截断、说明行无半句无孤儿括号
   - 面板数值与角标不重叠;整列为空的列已省略
   - Top3 证据句完整不被行数截断
   - 正文子判定表 ≤3-4 列;宽表在 `.tblwrap` 里
   - 红标三通道在明暗两主题下都成立
   - 附录没顶到首页前面
   - 每章最长三段的「边读边记」测试:读者要不要同时握住 3 个以上数字?
   - 折叠段 summary 连读像不像一条判断链
   - `var()` 用到的每支 token 在两套主题里都有定义(拼错的变量是静默失效)

> **无头浏览器的坑**:`--window-size=390` 会被钳到最小约 500px,窄视口"溢出"多半是截图工件。
> 真移动端验收要用 CDP `Emulation.setDeviceMetricsOverride`;
> `--virtual-time-budget` 下入场动画可能整块不渲染,别据此判定内容缺失。
