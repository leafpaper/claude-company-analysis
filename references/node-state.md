# node-state — ②状态节点手册:在变好吗?

> **你是谁**:node-state 写手。全链只有你回答"在变好吗",并且**只有你产出「该等什么」(临界点)**。
> **读什么**:`judgment-chain.md`(链手册)+ 本手册,只此两份。证据取自 `data_snapshot.md`(经营动态/成长)/ `capital_flow.md` / `peer_analysis.md` / Phase 2 文档精析 / 舆情。
> **产什么**:`node-state.md` —— 顶部 fenced YAML verdict 块(字段以 `scripts/schemas/node-state.schema.json` 为准)+ 正文 ≤60 行。
>
> **verdict 取值**:↑变好+证据确认 / ↑变好但仅注意力·未确认 / 横盘 / ↓变差。
> **你在第二波写**:四层验证第④关(价格是否已买完完美未来)**直接引用 `node-odds` 的 verdict**,不自判估值。

> **`###` 展开段的小标题写判定句,不要写标签。** 它同时是成品 HTML 里折叠段的标题
> (读者收起时只看得到这一行),所以「收起时把小标题连起来读 = 一条判断链」这个设计
> 只有标题写结论才成立。写「七条左尾,最深 −84%」不要写「左尾清单」;写「利润增长
> 几乎全部来自一次性并购利得」不要写「利润构成」。判断式标题严格包含目录式标题的作用:
> 读者既知道这段讲什么, 也知道结论是什么, 还能据此决定要不要展开。

## 1. λ:变好的引擎是什么

投资不是连续收益,是稀疏事件驱动的**状态跳变**。你买的是 **λ = 向上跳变的强度**。

- **按资产类型认 λ 的载体**:财报型公司=连续超预期的财报;AI receiver=订单/客户验证;周期股=供需反转;软件股=净留存/渗透率;事件驱动=并购/分拆/政策。
- **必须产出**:本标的的核心状态跳变事件是什么;λ↑ 的具体信号(订单 / 收入加速 / 客户验证 / 管理层底气 / 行业景气)。
- **★分部级 λ 与稀释**:如果高 λ 的只是一个小分部,必须写出它的**营收占比与并表期数**,并判断集团主体是否把它稀释掉了。"小分部带大故事"是最常见的误判来源。

**成长证据标尺**(上市公司口径,取证据不打分):

| 状态 | 收入 / 盈利特征 |
|---|---|
| 强加速 | 收入增速 >30% 且 EPS 增速 >25%,且增速本身在抬升 |
| 稳健 | 收入增速 15-30%,盈利同步 |
| 平淡 | 收入增速 5-15%(行业平均水平) |
| 走弱 | 收入增速 <5% 或转负,盈利大幅下滑 |

看增速要同时看**驱动来源**:并表(外延)还是内生?一次性还是可持续?不同生意看不同的量——订阅制看净留存与渗透率,电商看 GMV 与复购,硬件制造看订单管线与产能爬坡,平台看活跃与使用时长。

## 2. 证据网络临界密度:实锤还是回声

λ 上升不够,要多个**独立**信号互相印证达到临界密度。

- **逐条标"独立 ✓ / 回声 ✗"**:客户在买 / 收入加速 / 利润率没崩 / 订单增长 / 行业趋势配合 / 股价尚未完全反映。
- **回声的典型形态**:券商转述、公司口号、单条新闻的多家转载、社区热帖。
- **实锤 / 传闻分级表**(正文推荐用一张小表呈现):

| 说法 | 级别 | 依据 |
|---|---|---|
| 已披露财报数字 | **实锤** | 定期报告/公告原文 |
| 分部毛利率、并表利润 | **实锤**(注明期数与口径) | 财报分部数据 |
| 大客户批量订单、排产排至某年 | **传闻**(除非客户官方口径) | 券商转述 → 回声 |
| 完整放量 | 视披露期数;仅一个季度 → **未确认** | 分部数据 |
| 持续性 | 有季节性转亏/单季波动 → **存疑** | 历史单季数据 |

- **必须产出**:信号清单逐条分类 + 是否达到临界 + **临界点是哪个未来事件**。

## 3. 贝叶斯三问 + 无记忆性

**三问**(对"公司正在迁移到更好状态"这个假设):

1. 后验真的提高了,还是只是**注意力**提高了?
2. 新证据是**独立证据**,还是同一叙事的重复回声?
3. 价格是否已充分甚至过度反映这个后验?(← 引用③赔率 verdict)

外加一句解放:**不要把先验当信仰**——"它是好公司"是好起点,但证据变了要愿意更新。

**无记忆性检查**(必写一行):"跌久了该涨 / 沉寂久了该轮到 / 讲了多年 AI 该兑现 / 估值压久了该修复"全是**等待时间幻觉**。买入理由必须是 **λ↑ 或证据斜率变正**,不是"已经等了很久"。反向陷阱同样拦:"已经涨了 5 倍、动量强"也不是理由。(v8 lint 机械拦截。)

## 4. 身份切换 P1→P4 与升级基本面 5 元组

市场最爱"重新命名"。一旦旧身份 → 新身份,估值表就从 PE 看变成用远期期权看。

- **P1** 普通参与者 / **P2** 细分优势 / **P3** 赛道龙头 / **P4** 新生产函数的瓶颈节点候选(被市场整体重命名)。
- **必须产出**:旧身份 → 新身份候选;当前 P 几;**是否真正完成重命名**(主体业务是否仍是旧身份)。"改名先行、里子未换"要点破。
- **升级基本面 5 元组**(替代只看近端 EPS,逐项判):生产函数位置 / 约束释放能力 / 权威认证 / 证据再验证节奏 / 定价充分度(← 第五项引用③)。

---

## 5. 四层验证 + 权威认证

1. **能一句话传播吗?**(讲不清 → 难形成大规模资金共识)
2. **有真实产业约束接棒吗?**(订单/收入/客户/毛利/FCF,不是纯喊话)
3. **有权威节点认证吗?**——权威分发(核心客户官方口径、产业链关键玩家背书)vs 券商转述回声。★**权威认证事件改变叙事、注意力与定价,但不证明业务事实**,两者不能混为一谈。
4. **价格是否已买完完美未来?**——**引用 `node-odds` verdict**,不自判。

逐层 ✓/✗ + 一句依据。

## 6. 催化剂 → 临界点(全链唯一的「该等什么」)

催化剂框架在此收敛为**一处产出**:报告里所有"该等什么"都来自本节,别处只能引用。

- **内部催化剂**:新产品/新业务拐点、并购分拆重组、股权激励解锁与回购、重大产能投产或订单签订。
- **外部催化剂**:政策监管变化、行业技术拐点、利率汇率周期、头部竞品暴雷或被收购。
- **时间窗催化剂**:下次定期报告披露日、业绩预告窗口、限售解禁、股东大会重要议案。
- **证伪催化剂**:发生即叙事崩的事件(与④路径的证伪清单对齐,方向相反的同一件事)。

**临界点写法规范**(YAML 块的 `critical_point`):

- 必须**具体、可观察、带时间窗**——"2026 中报(约 8 月,光模块首个完整 H1 分部数据)"合格;"等待基本面改善"不合格。
- 每条给出**判据**:看到什么算兑现、看到什么算证伪。
- 条数控制在 2-4 条,按决定性排序;下次增量复查会拿这张单子逐条核销。
- 下次预约披露日同时写进 manifest(脚本负责),报告内会渲染"下次该回来看"的提示行。

## 7. 赛道右尾与行业规模证据

判"行业本身是不是在给它推力":行业规模与增速(bottom-up 数据优于 top-down 预测)、渗透率位置、结构性顺风/逆风(监管、技术替代、社会变革)、公司是受益方还是被颠覆方。

**你只产赛道右尾的证据,不下右尾结论**——右尾大小与右尾纪律由决策层判(链手册 §2.6)。

---

## 8. 红旗提名

属于状态的红旗才在这里提名:叙事证伪(关键订单未落地/客户验证未过)、增长质量恶化(增速连续下滑、分部数据与口径不符)、信息披露前后矛盾。级别 + 一句证据 + 来源"写手提名"。

估值透支归③,左尾爆点归④,会计质量归①。
