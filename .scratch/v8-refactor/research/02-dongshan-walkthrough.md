## 2. 节点② 状态:在变好吗? → **判定:↑变好但未确认(注意力先行、业绩待验证)**

- **λ 载体**(4.11 五机制块保留): 光模块放量 + 大客户验证。变好的引擎=索尔思光电,毛利率 36.74% 全集团最高、2026Q1 集团归母 +143.47%(扣非 +166.99%,非经常仅 5,061 万,经营性实锤)。
- **分部稀释**: 高 λ 分部仅占 FY2025 营收 3.58%(且仅 Q4 并表一个季度),96% 仍是 PCB/触控老本行——典型"小分部带大故事"。
- **实锤/传闻分级**: 利润翻倍=实锤;光模块毛利=实锤;大客户(NVIDIA/Meta/Google)批量订单排至 2028=**传闻**(全是券商转述,无客户官方背书——叙事四关第③关 ✗);完整放量=传闻(仅 Q4 一季 14.36 亿);持续性=存疑(FY2025Q4 扣非 −1.05 亿季节性转亏)。
- **身份切换**: PCB 制造商 → "东方 Lumentum/算力追光者",市场已按新身份定价(一年涨约 5 倍),业务本体未跟上(3.58%)——P1→P4 改名先行、里子未换。
- **临界点(=该等什么,全链唯一产出处)**: 2026 中报(约 8 月,光模块首个完整 H1 分部数据)+ 谷歌 200G EML 验证结果(2026Q2 末)。催化剂框架并入此处后,v7.1 里写 7 处的"等中报"收敛为一处权威(R5 消)。
- **无记忆性检查**: 不存在"跌久该涨"诱惑;反向陷阱=把"涨 5 倍动量强"当理由——已拦截。

## 3. 节点③ 赔率:贵不贵? → **判定:买完完美未来(无 slack)——区间两端同向,判定成立**

- **P=F+N**: F≈1,000 亿(光模块以外成熟主业年化归母约 50 亿 × 制造业 20x),N≈4,000 亿 = 市值约 5,000 亿的 **80%**——为一块占营收 3.58% 的业务多付 4,000 亿;判定 **obligation 非 option**(242.9x PE 下放量是必须交付的任务);N'/N ≫ F'/F(叙事增速远超基本面增速)。
- **反向 DCF**: 现价隐含 净利 +50%/年×5 年(历史:FY23 −17%、FY24 −45%、FY25 才 +28%)+ 光模块占比 3.58%→30%+ + 净利率 3.73%→8-10% + 退出仍 30x——**过度乐观**,逐条配证伪(任一年净利增速 <30%、H1 光模块 <40 亿、净利率回落 <5%)。
- **★区间锚(新规则首次落地)**: [SOTP 1,050 亿 ≈ 57 元, DCF 概率加权 1,632 亿 ≈ 89 元]。
  - v7.1 做法: 报单点锚 89 元,SOTP 写"交叉验证方向一致"——55% 分歧被带过(违反 v4.2 自己的 20% 红线,C4)。
  - 新链做法: 分歧摊开。现价 273 元 = 区间高端的 3.06 倍、低端的 4.79 倍——**区间两端判定同向(极贵),赔率判定成立,无需降档**。分歧原因显式: SOTP 对光模块给 40x 已慷慨但只认已并表利润,DCF 允许 15% CAGR 温和放量——两把尺子量的东西不同,分歧是信息。
- **ΔP 一句话**: 撑起 5 倍上涨的是散户拥挤+两融杠杆+题材压缩,非权威背书+真放量——不健康,赔率更脆(细节§八)。
- **红旗归家**: 2 个 🟠 估值红旗(PB 22.09 近 1 年 100% 分位;PB/ROE 错配 25.7 倍)+ 🟡 PS 100% 分位、🟡 股息率 0.02% **只在本节点出现一次**(旧制度要求 ≥3 处闭环、6.2 曾自我记账"本节为第三处闭环")。

## 4. 节点④ 路径:扛得住吗? → **判定:高尾险·扛不住**

- **左尾清单**: ① 商誉 47.69 亿减值(单季 +26.5 亿并购形成,对赌未披露;刨掉商誉清算净值约 −2~8 亿,地板薄到近资不抵债)→ 最差 5 元(−98%);② 叙事证伪 → 80% 想象溢价回吐(−86%~−98%);③ 关键人物(袁氏父子控盘 30.05% 高质押 + 索尔思技术团队绑定);④ 散户 8.17 万→30.60 万户(约 2 个月 2.8 倍)+ 两融高于 60 日中位 33.4% + 大宗折价 −7.5% → 踩踏放大回撤至 −75%~−98%;⑤ 质押补仓压力与 ④ 共振。
- **高信仰股体检**: 估值高(PE 242.9x 全行业最贵)✅强 / 波动高(一年 +758%)✅强 / 散户多 ✅强 / 媒体+杠杆活跃 ✅ / 关键人物依赖 ✅ —— **5/5 满分**,下跌时是波动放大器。
- **回报路径证据**(5.6 降格后只产证据、不再给仓位): 概率加权 12-24 月收益约 −69%、年化约 −45%;乐观情景兑现仍 −44% 且中途 −50% 回撤——时间/机会成本极高;假阳性成本=传闻当实锤追入遇三重杀。
- **旧 6.1 快筛(已并入 audit 静默机算)**: 净利暴跌>50%?否(+143%)/负债率>70%?否(63.69%,警示)/质押>总股本50%?否(约8.7%)/审计变更?无/CFO 离任?无/🔴≥2?否(0 个)——**0 触发 → 无自动 🔴 → 决策层封顶不启动**。报告零篇幅,不再养"全 PASS + 快筛PASS≠安全免责"一节(R6 消)。

## 5. 决策层:三元组乘法 → **等证据临界(观察)+ 期权小仓 ≤2-3%**

- **三元组**: [状态=↑未确认 | 赔率=买完完美未来 | 路径=高尾险] → 查映射表第二行 → **等证据临界(观察) 或 期权仓(小),看右尾大小**。
- **右尾评估**: 赛道右尾真实(AI 光模块 2026 年市场 +52%、1.6T 量产元年、200G EML 稀缺)但本票四条右尾特征只对上一条半(FCF 为负、估值起点全行业最贵)→ **主基调先别动、现价 0 仓位持币(等待=选择权);想赌右尾最多总资金 2-3% 期权小仓、设硬止损**。
- **三分结论**: 好公司?**部分是**(← 直接引用质地节点判定,决策层不再自判)· 好下注?否(三乘子两差一弱)· 好价格?否(现价为锚区间高端的 3 倍以上)。
- **该等什么**: 2026 中报(约 8 月)+ 谷歌验证(2026Q2 末)+ 价格条件(回调至乐观情景区约 160 元以内)。
- **证伪/退出**: H1 光模块营收 <40 亿或毛利率 <30%;谷歌验证未过/订单证伪;商誉任一减值;现金流持续恶化/营收增速连续 <25%。
- **封顶检查**: 无致命红旗触发 → 不封顶(若负债率越 70% 或 🔴≥2,档位将机械封死「回避」)。
- **信仰陷阱五弊端自检**: 逐条 ✓(与 v7.1 7.4 同)。
