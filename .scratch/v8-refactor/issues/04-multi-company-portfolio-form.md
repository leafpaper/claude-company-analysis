# 04 多公司对比/组合视角的产品形态

Type: grilling
Status: closed (2026-08-12)

## Question

这个功能到底是什么?需要钉下:

- 形态:横向对比表?组合仪表盘?筛选排序视图?
- 对比对象从哪来:已分析过的公司?当前持仓?任意指定?
- 数据从哪来:已有报告的结构化摘要(card-metadata?)还是要新增跨报告的结构化输出?
- 产出物长什么样、放在哪(Inves-Report 站点?独立页面?)

答案清晰后,把「组合视角的数据源与持仓联动细节」从地图雾区切成新 ticket。

## Answer (2026-08-12 grilling 定稿)

**一句话:多公司对比 = 产业链同行对比页,回答「同行组里钱该放哪家」;组合视角划出 v8.0。**

1. **核心问题**:同行组里,钱该放哪家。不做跨行业资金配置——用户明确否掉跨行业比较(「对比应该是相关产业的同行业」)。
2. **同行口径**:产业链相关,不是证监会窄行业分类。东山精密↔中际旭创(AI 服务器 PCB↔光模块,不同 sector 同算力硬件链)算同行。
3. **组合视角处置**:跨行业持仓仪表盘、watchlist 联动整体划出 v8.0,进地图 Out of scope(同 Living Thesis 待遇,将来要做另起一张图)。原雾区「组合视角的数据源与持仓联动细节」条目删除。
4. **发起流程**:锚定一家公司发起 → 系统按产业链相关性自动查同行候选(三条路:Longbridge 产业链/成分股工具、报告库 Phase 1 peer_analysis 现成对标、模型基于业务描述判断兜底;出 5-8 家)→ **候选必须经用户确认/增删后成组**(产业链边界模糊,自动查有噪声,用户把关)。
5. **底料 = 全报告制**:对比只在有完整报告的成员间进行;确认成组时列出缺报告成员,用户决定先跑哪几家、可分批。否掉「锚深同行浅」(答不了核心问题)与「peer-lite 轻判断管线」(表面判断风险 + 多维护一条管线)。理由:质量优先成本其次;报告进库可复用;流水线只维护一条。
6. **产出物 = 一页对比,上下两半**:
   - 上半:各家决断卡 / 四问 verdict / 区间锚 / Top3 **机器装配并排**(复用 v8.0 摘要层结构化产物,零新判断)。
   - 下半:**「组内裁决」= 新增的具名判断节点**——写手读各家判断链产出,给出排序 + 每家一句原因;只引用各报告结论、不自产新证据(同 05 面板「结论行引用子判定」原则)。纯按赔率数字机械排序被否:跨报告比数字是表面映射。
   - 否掉「完整对比报告」(行业格局/交叉验证章节)——与单报告重叠,又造复述层。
7. **交付**:Inves-Report 站点独立对比页(如 compare/{组slug}/)+ 本地 md 底稿,复用现有发布链路;首页对比卡与单报告卡并列,卡点进对比页,对比页内每家可点回单报告;视觉规格并入 [07 交付形态 prototype](07-delivery-prototype.md)一起定。
8. **新鲜度**:对比页每家标报告基准日;超龄标「陈旧」并提示先增量复查(阈值数字留给 spec,复查机制归 [03](03-incremental-review-requirements.md));成员报告更新后**手动重跑**对比命令→重新装配+重跑裁决;不做自动联动(LLM 裁决节点不适合无人值守自动重跑)。

留给 spec 的细节(本票不钉):命令形态(如 `--compare 锚公司`)、组 slug 命名、陈旧阈值具体天数、候选查询的工具优先级。
