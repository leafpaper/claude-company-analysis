# 06 报告目标结构

Type: grilling
Status: resolved
Blocked by: 02, 05

## Question

9 章节砍成什么目标结构?需要决定:

- 目标章节清单:哪些合并、哪些删除、哪些降为附录
- 信息层级:结论 → 证据 → 附录的组织方式(结论先行、全说人话)
- 「赚不赚钱」层与红标([红标机制定义](05-red-flag-marking.md))在结构中的位置
- 长度目标:主体控制在什么量级,什么内容允许长

前置:[判断链收敛方案](02-judgment-chain-convergence.md)定了链,结构才知道每章承载链的哪一段。

## Answer

**章节=判断链**:9 章收敛为「首页一眼结论(机器装配:决断卡五行→赚钱面板→Top3 红旗→3-5 句人工导读)→ ①质地 ②状态 ③赔率 ④路径 ⑤怎么办 → 附录 A-E(财务明细/行业对标/舆情资金底稿/红旗总清单/数据来源与缺口)」。旧 §二§三 拆进质地章+附录,§八 降为附录C 底稿(「谁在买」证据一处权威,被赔率 ΔP/路径拥挤度引用),§九 归附录E;红旗总清单落附录D(机器产物,装配红标与 Top3 的数据源,每条红旗叙述仍归家所属章)。

**信息层级=最硬证据制**:每章 verdict 块先行 + 子判定表(判定+最硬证据 1-2 条,机制具名)+ 必要展开段;完整表格/时间序列/计算过程全部下沉附录。数字唯一 home(所属权威章或附录),异地复现必须是带来源的引用;机器装配渲染(决断卡/面板/Top3)不受此限——R7 就地击杀(散户数字 5 处人工叙述→1 权威+1 引用+机器渲染)。

**长度=软目标+章预算**:主体 300-400 行(首页≤40/质地≤70/状态≤60/赔率≤70/路径≤60/怎么办≤50),超预算不硬删、写手自检可否下沉;附录不限长。

**铁律验收**:东山精密 33 小节全量映射见 [../research/06-dongshan-structure.md](../research/06-dongshan-structure.md)——零孤儿(删除 7 项全部对应 02 判死机制)、主体实测 ~275 行装得下偏复杂案例、面板/红标位置与 05 摘要层决策吻合。
