## ★★ v7.1 写作风格契约（最高优先级——违反即重写）

> 用户实测反馈:旧报告**杂乱、读不下去、满屏术语、读完不知道该不该投**。本契约把报告改成"**外行也能读懂、读完就能筛选好公司**"。框架(λ/P=F+N/状态后验…)只是**你脑子里的思考工具**,**写进报告时必须翻成大白话**(对照 `references/investment-decision-core.md` 的「人话词典」)。

**6 条铁律**:
1. **结论先行**:每个分析块**第一行**给一句加粗"**一句话**"人话结论,再给证据。读者扫小结就懂。
2. **全说人话**:正文**不出现裸术语**(λ/embedded obligation/证据临界密度/幂律生成器…)。概念用大白话讲,框架名只在**小标题的小括号**里淡化标注(如"…(状态评估)")。没读过那五篇文章的人必须能看懂。
3. **一个论点一个关键数字**:**杀掉数据堆砌**。同一组核心数字(如分部占比/估值分位/散户倍数)**只在显眼处说一次**,后文引用不重报;次要数据收进**紧凑表格**。
4. **正文无来源标签**:§一/§四 4.11/§五/§七 **不放内联** `[data_snapshot…]`/`[§X]`/`[Tushare:…]` 等来源标签,来源统一放 §九。(机械拦截 §一/§五/§七;§四 4.11 由 reviewer 把关——§四 维度证据仍保留 audit 标签做红旗闭环。)
5. **排版三段式**:每块 = **加粗结论 → 2-4 条短支撑 → 紧凑表格(次要数)**。短句,少分号,少嵌套。
6. **像那五篇文章写**:大白话 + 具体证据 + 好记的一句话 + 明确 takeaway(参照喊线/泊松的行文)。§一 借研报"投资要点"开头。

**两个筛选中枢(必做)**:
- **投资决断卡**(§一 顶部 + §七 详版,5 行人话):①是不是好公司 ②故事真不真 ③贵不贵 ④该不该买 ⑤怎么办——"是不是好公司(值得关注)"与"该不该买(时点)"**分开**给。模板见 investment-decision-core.md。
- **四维体检**(§四,借喊线):懂财报/懂叙事/懂估值/懂热点,每维一句结论 + 最硬一条证据。

**范例(BEFORE→AFTER)**:
- BEFORE:`【λ与证据临界密度】λ(向上状态跳变强度)定义…属"财报型+AI receiver混合"…[data_snapshot §2.1]`
- AFTER:**一句话:确实在变好,但主要是个"小分部"在变好,关键证据还没坐实——更像"热度先到、业绩还没跟上"。** → 变好的引擎(光模块,毛利36.7%)→ 份量还小(占营收3.6%)→ 证据"实锤/传闻"表 → 缺的最后一块=等中报。

## §五 估值、赔率与定价充分度（part3）

承接骨架 §五 的 placeholder。**方法论（v7.0）**：不以"DCF 概率加权单锚"为唯一说服力——先用 **P=F+N 分解 + 反向DCF 隐含预期 + 叙事分部SOTP** 判赔率/定价充分度，正向 DCF 仅作 F 的交叉验证。权威机制定义见 `references/investment-decision-core.md` §2 + `references/valuation-frameworks.md`。**每块出数字，缺数字 = 空话 = reviewer FAIL。**

★ **v7.1 写法**：用骨架的**人话标题**(把股价拆成"已赚到的 vs 对未来的想象" / "现价等于在赌它未来要做到什么" / "这波上涨谁在买" / "分开估" …)，每节第一行给一句话小结;术语转人话(P=F+N→F"已赚到的该值多少"+N"市场为未来想象多付的";embedded obligation→"市场要求它必须做到、做不到就跌");**正文无来源标签**(来源进 §九);一个论点一个关键数字。

- **5.1 价格分解 P = 基本面F + 叙事溢价N**（信仰陷阱）：给 **F、N 的金额** + N 占现价市值 % + N 在为什么定价 + **N 是 free option 还是 embedded obligation** 判定 + **N'/N vs F'/F**（驱动股价的是叙事增速还是基本面增速）。
- **5.2 反向DCF：市场隐含预期**（喊线④+信仰陷阱）：从现价倒推**隐含增长 / 终端利润率 / 退出倍数（具体数字）**，逐条 vs 历史/同业参照判可信度 + 给证伪条件 → 现价隐含预期 {可信/过度乐观/买完完美未来}。

- **5.4 叙事分部 SOTP：拆分不混账**（信仰陷阱解药①）：若 ≥ 2 条增长叙事且分部毛利/估值差异大 → **各分部各自合适倍数 + 各自证伪指标**，SOTP 合计 vs 现价；**禁用单一笼统倍数盖全公司**。
- **5.5 正向DCF（作为 F 的交叉验证）**（参照 Damodaran 7 步）：假设表（须从历史外推，与 §二 不内在矛盾）；乐观/基准/悲观（+最差，若 §二 SOTP 触发）；概率合理（极端 10/80/8/2 警告）；**永续 g < 折现 r（强制）**；**退出倍数 vs 同业当前+历史分位 sanity**；转型公司放松"终端利润率≈历史均值"硬锚时**须显式举证**；forecast vs actual 兑现度（`data_snapshot.md` §4）；估值锚表 → 概率加权 DCF（作交叉验证锚）。
- **5.6 回报与路径成本 + 技术面位置**：inline `technical_analysis.md` 技术面 6 维度 + 支撑阻力 + 基本面×技术面配合判断；回报表情景/概率与 5.5 **完全一致**，**含中途最大回撤 + 时间窗**；初始仓位 = `{amount}`；给概率加权 `{horizon}` 收益率 + 年化 + **时间成本/机会成本/假阳性成本**；**建议仓位**放本节末尾（不放 §一）。
