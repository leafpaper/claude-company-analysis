# Executive Summary 字段规范（v4.3 强制）

> Phase 3 写 §一 执行摘要时**必须**按本 schema 的字段名、顺序、必填性展开。禁止自创字段名（如"综合评级" / "量化分" / "定性修正" / "建议仓位"等变体 —— 均为历史漂移产物）。

---

## 固定字段（顺序锁定，全程说人话）

> v7.1：§一 是给**外行也能读懂**的决策仪表盘。**全说人话、不堆术语、正文不放来源标签。** 核心是「投资决断卡」——让读者一眼知道"是不是好公司、该不该买、该等什么"。

| # | 字段名 | 必填 | 格式 | 说明 |
|---|--------|:---:|------|------|
| 1 | **投资要点** | ✅ | 3-5 条 bullet，每条一句人话，先讲最重要的 | 像研报开头的"投资要点"，扫一眼掌握全局 |
| 2 | **一句话结论** | ✅ | 加粗 + 3 档方向（看多 / 看空 / **中性-分歧**）+ 1-2 句主要逻辑 | 读者扫一眼就能判断观点 |
| 3 | **投资决断卡** | ✅ | 5 行表：①是不是好公司 ②故事真不真 ③贵不贵 ④该不该买 ⑤怎么办（+该等什么）。每行一个结论 + 一句人话理由 | ★ **本报告权威结论**，与 §七 7.4 一致；"是不是好公司(值得关注)"与"该不该买(时点)"分开 |
| 4 | **估值锚** | ✅ | §五 综合估值锚的亿元数 / 每股 / 相对当前股价折让% | 来自 §五（P=F+N + 反向DCF + 叙事SOTP；DCF 作交叉验证） |
| 5 | **综合评分** | ✅ | `X.XX / 10` + **数据置信度**（高/中/低）+ 标注「基本面静态快照」 | ★ **快照非投资结论**，方向看「投资决断卡」 |
| 6 | **三大风险（Top 3）** | ✅ | 3 条 bullet，每条 ≤ 50 字；优先引用 audit_report 🔴 红旗 | 不多不少 3 条 |
| 7 | **三大机会（Top 3）** | ✅ | 3 条 bullet，每条 ≤ 50 字 | 不多不少 3 条 |
| 8 | **核心非共识判断** | 可选(1-3 条) | 1-3 条本报告与市场共识的关键分歧(纯标题/短句) | 由分析师直接给出，可省略 |

---

## ★ 保持干净:§一 禁止内联来源标签

§一 执行摘要是给人**快读的决策仪表盘**,所有字段一律用**干净叙述**,**禁止内联任何来源标签**:
`[data_snapshot §2.1]` / `[peer_analysis §3/§4]` / `[metrics.json:segments]` / `[audit #1]` / `[§五 5.1]` / `[缺口#1]` / `[WebSearch:…]` / `[Tushare:…]` / `[PDF:…]` 等——这些会把摘要变成脚注堆,严重伤可读性。

v7.1：不只 §一——**§四 4.11(状态评估)/§五(估值)/§七(决策) 这些"给人读判断"的分析正文也一律不放内联来源标签**,来源统一进 §九。anti_lazy_lint Rule 5 **机械检查 §一/§五/§七**;**§四 由 reviewer 把关 4.11 子节可读性**(§四 维度证据保留 audit 标签做红旗闭环,故不入机械规则)。(§六 红旗允许引 audit_report、§八 舆情允许带 URL、§九 是来源章。)

---

## 禁止出现的字段(历史漂移)

以下字段**不得**出现在 §一 执行摘要(已在其他章节承接):

| 禁用字段 | 原因 | 去哪里 |
|----------|------|--------|
| "综合评级"(强烈看好/有条件看好/谨慎/回避 4 档) | v4.1 已废 | 用「投资决断卡」第⑤行的**行动档位**(六档:核心仓/期权仓/等证据临界/不追高/减仓/回避，来自 §七) |
| "量化分 + 定性修正 + 调整后分" 多列 | v4.1 禁止打分换壳 | §二 评分总览(单列) |
| "建议仓位: ≤N% 总资产" | 不是"事实",是"建议" | 放 §五 (5.6) 末尾 |
| "尽调优先级 / 需补查问题" | 与 §八 信息缺口重复 | §八 |
| "主要假设 / 关键假设敏感度" | 与 §五 DCF 敏感性重复 | §五 |
| 内联来源标签 `[data_snapshot…]`/`[§X]`/`[缺口#N]`/`[Tushare:…]` 等 | 摘要应清爽,不是脚注堆 | 来源在 §二–§八 标注 |

## 示例(v4.3 合规版)

```markdown
## §一 执行摘要

**投资要点**:
- 核心资产安世半导体(车规功率分立全球 Top 3)的控制权被荷兰政府冻结——这是决定一切的胜负手。
- 2025 年度大概率"洗大澡"预亏 90-135 亿,但多为一次性账面减值,不是经营崩了。
- 现价已把约 40% 的悲观情形定价进去(PB 近 1 年仅 2% 分位),坏消息基本出尽。
- 公司是好公司;但现在买等于赌"控制权能否恢复",是二元结局,适合小仓博弈、别重仓。

**一句话结论**: **中性-分歧** —— 好资产 + 坏处境,赌的是 2026 年控制权能否恢复:恢复则大幅重估,不恢复则沦为"净现金 + 壳"。

### 投资决断卡（一眼看懂——"是否适合投资"的答案）

| 问题 | 结论 | 一句话理由（说人话） |
|------|:---:|------|
| ① 是不是好公司? | ✓ 是 | 安世车规功率分立全球 Top 3、2024 独立净利 +22.97 亿,资产本身优质 |
| ② 故事真不真? | 真，有变数 | 控制权被荷兰政府冻结是真风险(不是炒作),也是核心不确定性 |
| ③ 现在贵不贵? | 便宜 | PB 近 1 年仅 2% 分位,已把 40% 悲观情形定价进去 |
| ④ 现在该不该买? | 小仓博弈 | 赔率好,但胜负全看控制权能否恢复——二元结局,不确定性高 |
| ⑤ 我该怎么办? | 期权小仓 + 等控制权落地 | 别重仓;重点等 2026 控制权恢复进展 / 年度减值落地这两个事件 |

**估值锚**: **概率加权 DCF ≈ 383 亿 / 30.8 元**(4 情景;乐观 20% / 基准 50% / 悲观 25% / 最差 5%)。当前 28.35 元相对此锚折让 8.6%。

**综合评分**: **4.66/10**（基本面静态快照,非投资结论）· **数据置信度**: 中(2025 年度减值明细待披露)

**三大风险(Top 3)**:
1. 🔴 荷兰控制权危机持续,Nexperia 可能被强制出售
2. 🔴 Altman Z=1.58 破产风险区 + 商誉占净资产 63%
3. 🟠 治理 red flag 组合(CFO 辞职 + 审计机构切换 + 大股东集中质押)

**三大机会(Top 3)**:
1. Nexperia 2024 独立净利 +22.97 亿,车规功率分立 Top 3 地位稳固
2. ODM 业务已剥离,战略叙事清晰化
3. PB 近 1 年 2% 分位,市场已消化悲观预期

**核心非共识判断**:
1. 2025 年度预亏将接近上限 -135 亿(big bath 假说)
2. 当前 PB 1.04 已充分定价 40% 悲观概率
```
