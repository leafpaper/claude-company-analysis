# Executive Summary 字段规范（v4.3 强制）

> Phase 3 写 §一 执行摘要时**必须**按本 schema 的字段名、顺序、必填性展开。禁止自创字段名（如"综合评级" / "量化分" / "定性修正" / "建议仓位"等变体 —— 均为历史漂移产物）。

---

## 7 固定字段（顺序锁定）

| # | 字段名 | 必填 | 格式 | 说明 |
|---|--------|:---:|------|------|
| 1 | **一句话结论** | ✅ | 加粗 + 3 档方向（看多 / 看空 / **中性-分歧**）+ 1-2 句主要逻辑 | 读者扫一眼就能判断观点 |
| 2 | **估值锚** | ✅ | §五 综合估值锚的亿元数 / 每股 / 相对当前股价折让% | v7.0：§五 以 P=F+N + 反向DCF + 叙事SOTP 判赔率，DCF 仅作交叉验证锚 |
| 3 | **综合评分** | ✅ | `X.XX / 10` + **数据置信度**（高/中/低）+ 标注「基本面静态快照」 | 与 §四 一致；★ **此为快照非投资结论**，方向看第 7 字段「决策结论」 |
| 4 | **三大风险（Top 3）** | ✅ | 3 条 bullet,每条 ≤ 50 字;优先引用 audit_report 🔴 红旗 | 不多不少 3 条 |
| 5 | **三大机会（Top 3）** | ✅ | 3 条 bullet,每条 ≤ 50 字 | 不多不少 3 条 |
| 6 | **核心非共识判断** | 可选(1-3 条) | 1-3 条本报告与市场共识的关键分歧(纯标题/短句,不写数学推导) | v6.0: 不再依赖已删除的 Phase 5;由分析师直接给出非共识判断 |
| 7 | **决策结论** | ✅ | 来自 §七 投资决策内核：决策三元组 [状态 ｜ 赔率 ｜ 路径] + 三分结论（好公司?/好下注?/好价格?）+ 行动档位（六档之一）+ 该等什么 | 替代旧"投资方向综合判定"；**本报告权威结论**，与 §七 7.4 一致 |

---

## ★ 保持干净:§一 禁止内联来源标签

§一 执行摘要是给人**快读的决策仪表盘**,所有字段一律用**干净叙述**,**禁止内联任何来源标签**:
`[data_snapshot §2.1]` / `[peer_analysis §3/§4]` / `[metrics.json:segments]` / `[audit #1]` / `[§五 5.1]` / `[缺口#1]` / `[WebSearch:…]` / `[Tushare:…]` / `[PDF:…]` 等——这些会把摘要变成脚注堆,严重伤可读性。

来源标注属于 §二–§八 对应正文(财务表、维度证据、估值、舆情那里本来就带)。**§一 只给结论与逻辑,不给出处。** anti_lazy_lint Rule 5 会机械检查 §一 是否混入来源标签,混入即不通过。

---

## 禁止出现的字段(历史漂移)

以下字段**不得**出现在 §一 执行摘要(已在其他章节承接):

| 禁用字段 | 原因 | 去哪里 |
|----------|------|--------|
| "综合评级"(强烈看好/有条件看好/谨慎/回避 4 档) | v4.1 已废 | 用第 7 字段「决策结论」的**行动档位**(六档:核心仓/期权仓/等证据临界/不追高/减仓/回避，来自 §七，与旧 4 档评级不同) |
| "量化分 + 定性修正 + 调整后分" 多列 | v4.1 禁止打分换壳 | §二 评分总览(单列) |
| "建议仓位: ≤N% 总资产" | 不是"事实",是"建议" | 放 §五 (5.6) 末尾 |
| "尽调优先级 / 需补查问题" | 与 §八 信息缺口重复 | §八 |
| "主要假设 / 关键假设敏感度" | 与 §五 DCF 敏感性重复 | §五 |
| 内联来源标签 `[data_snapshot…]`/`[§X]`/`[缺口#N]`/`[Tushare:…]` 等 | 摘要应清爽,不是脚注堆 | 来源在 §二–§八 标注 |

```markdown
## §一 执行摘要

**一句话结论**: **中性-分歧** —— 核心优质资产(安世半导体)控制权被荷兰政府冻结,短期 2025 年度预亏 90-135 亿"大澡堂"几成定局;若 2026 年控制权恢复则估值大幅重估,否则本公司将沦为"80-100 亿净现金+壳"。

**估值锚**: **概率加权 DCF ≈ 383 亿 / 30.8 元**(4 情景;乐观 20% / 基准 50% / 悲观 25% / 最差 5%)。当前 28.35 元相对此锚折让 8.6%。

**综合评分**: **4.66/10**（基本面静态快照，非投资结论）· **数据置信度**: 中(2025 年度减值明细待披露)

**三大风险(Top 3)**:
1. 🔴 荷兰控制权危机持续,Nexperia 可能被强制出售
2. 🔴 Altman Z=1.58 破产风险区 + 商誉占净资产 63%
3. 🟠 治理 red flag 组合(CFO 辞职 + 审计机构切换 + 大股东集中质押)

**三大机会(Top 3)**:
1. Nexperia 2024 独立净利 +22.97 亿,车规功率分立 Top 3 地位稳固
2. ODM 业务已剥离,战略叙事清晰化
3. PB 近 1 年 2% 分位,市场已消化悲观预期

**核心非共识判断**:
1. 2025 年度预亏将接近上限 -135 亿(big bath 假说)
2. Nexperia SOTP 应扣 10-20% 控制权折让,而非全值
3. 当前 PB 1.04 已充分定价 40% 悲观概率

**决策结论**（来自 §七 投资决策内核）:
- **决策三元组**: [状态后验: ↑变好但未独立确认 ｜ 赔率: 已 price-in ｜ 路径: 高尾险]
- **三分结论**: 好公司? 部分是 · 好下注(现价)? 否 · 好价格? 否
- **行动档位**: **不追高（贵但优质）+ 期权小仓** · **该等什么**: 控制权恢复 / 2025 年度减值落地
```
